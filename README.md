# Shopping Dataset Analysis using Pandas

## Objective
Perform data exploration and cleaning using Python Pandas.

## Tasks Performed
- Loaded CSV dataset
- Explored data using head(), tail(), shape()
- Handled missing values
- Removed duplicates
- Filtered rows and selected columns
- Created derived column: total_amount
- Saved cleaned dataset

## Technologies Used
- Python
- Pandas
- NumPy
- Jupyter Notebook

## Files Included
- shopping_data_analysis.ipynb
- cleaned_shirts_dataset.csv
- shirts.csv
